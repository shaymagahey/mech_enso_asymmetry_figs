These files were used to generate the figures in Magahey et al., submitted to Journal of Climate in November 2026.

Heat budget:
functional_heatbudget_e3sm.ipynb
advection_rd_ml.py
vertical_advection_ml.py
Need advection and vertical advection scripts to run the functional driver script. 

pd_npmm_e3sm1.py: generates e3sm1 npmm index

composite_functions.py: contains functions to composite el nino/ la nina

calc_npmm_npo.py: calculating npmm and npo indices (npo was not used in this paper)

The rest of the figures pull from these codes.
